# Hello, I'm Douglas Fernandes 👋

## Building safer ways to work with AWS

I'm an AWS and infrastructure-as-code enthusiast interested in creating tools
that make cloud environments easier to understand, document, and evolve.

My current focus includes:

- AWS architecture and cloud operations;
- Terraform and infrastructure as code;
- safe, deterministic automation;
- adoption and documentation of existing infrastructure;
- tools designed with clear operational boundaries.

I believe useful cloud tooling should be transparent about what it does,
careful with credentials and runtime data, and supported by reproducible tests
and practical documentation.

I publish selected projects for public collaboration after documentation,
licensing, security, and sanitization reviews are complete.

## Criando formas mais seguras de trabalhar com AWS

Sou entusiasta de AWS e infraestrutura como código, com interesse em criar
ferramentas que tornem ambientes de nuvem mais fáceis de compreender,
documentar e evoluir.

Meus focos atuais incluem:

- arquitetura AWS e operações em nuvem;
- Terraform e infraestrutura como código;
- automação segura e determinística;
- adoção e documentação de infraestruturas existentes;
- ferramentas com limites operacionais claros.

Acredito que boas ferramentas para nuvem devem explicar claramente o que
fazem, tratar credenciais e dados de execução com cuidado e contar com testes
reproduzíveis e documentação prática.

Publico projetos selecionados para colaboração após concluir as revisões de
documentação, licença, segurança e sanitização.
